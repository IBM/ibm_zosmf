# Ansible role: zmf_swmgmt_add_pswi
The collection [ibm_zosmf](../../README.md) provides an [Ansible role](https://docs.ansible.com/ansible/latest/user_guide/playbooks_reuse_roles.html), referred to as `zmf_swmgmt_add_pswi`, to add a portable software instance (PSWI) using the z/OSMF Software Management REST API.

For guides and reference, see [Docs Site](https://ibm.github.io/z_ansible_collections_doc/ibm_zosmf/docs/source/roles/zmf_swmgmt_add_pswi.html).
